MINEWARP WEBSITE — PRIVATE WHITELIST SERVER
===========================================

Files:
- index.html     Main website
- style.css      Responsive styling
- script.js      Mobile menu and navigation behavior
- thumbnail.png  Your MineWarp portal image
- assets/thumbnail.png  Copy of the image

Privacy:
- The Minecraft server IP is intentionally not displayed.
- There is no copy-IP button or public server-address field.
- The website describes MineWarp as a private, whitelist-only community.

How to use:
1. Keep all files together in the same folder.
2. Open index.html in your browser to preview.
3. Upload the folder contents to your web host when ready.

Note: Enable the whitelist on the Minecraft server itself to enforce private access.
